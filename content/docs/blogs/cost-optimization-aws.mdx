# AWS Cost Optimization Strategies for Modern Applications

Cloud costs can spiral out of control quickly. Here's how we reduced our AWS bill from $120K to $70K per month while actually improving performance and reliability.

## Understanding Your AWS Bill

Before optimizing, you need visibility:

### Enable Cost Allocation Tags

```bash
# Tag all resources
aws resourcegroupstaggingapi tag-resources \
  --resource-arn-list arn:aws:ec2:us-east-1:123456789012:instance/i-1234567890abcdef0 \
  --tags Environment=production,Team=platform,CostCenter=engineering
```

### Set Up Cost Anomaly Detection

```python
import boto3

ce = boto3.client('ce')

# Create anomaly monitor
response = ce.create_anomaly_monitor(
    AnomalyMonitor={
        'MonitorName': 'ServiceMonitor',
        'MonitorType': 'DIMENSIONAL',
        'MonitorDimension': 'SERVICE'
    }
)

# Create anomaly subscription
ce.create_anomaly_subscription(
    AnomalySubscription={
        'SubscriptionName': 'CostAlerts',
        'MonitorArnList': [response['MonitorArn']],
        'Subscribers': [
            {
                'Type': 'EMAIL',
                'Address': 'devops-team@example.com'
            }
        ],
        'Threshold': 100.0,
        'Frequency': 'IMMEDIATE'
    }
)
```

## Compute Optimization

### Right-Size EC2 Instances

Use AWS Compute Optimizer:

```bash
# Get recommendations
aws compute-optimizer get-ec2-instance-recommendations \
  --instance-arns arn:aws:ec2:us-east-1:123456789012:instance/i-1234567890abcdef0 \
  --query 'instanceRecommendations[].recommendationOptions'
```

### Use Spot Instances for Non-Critical Workloads

```yaml
# EKS Node Group with Spot instances
apiVersion: eksctl.io/v1alpha5
kind: ClusterConfig
metadata:
  name: production-cluster
  region: us-east-1

managedNodeGroups:
  - name: spot-workers
    instanceTypes:
      - m5.large
      - m5a.large
      - m5n.large
    minSize: 3
    maxSize: 20
    desiredCapacity: 6
    spot: true
    labels:
      workload-type: batch
    tags:
      k8s.io/cluster-autoscaler/enabled: "true"
```

### Implement Auto-Scaling

Save on idle capacity:

```python
import boto3
from datetime import datetime

asg = boto3.client('autoscaling')

# Scale down during off-hours
def scale_for_time():
    current_hour = datetime.now().hour
    
    if 22 <= current_hour or current_hour <= 6:  # 10 PM to 6 AM
        min_size, desired = 1, 2
    elif 9 <= current_hour <= 18:  # Business hours
        min_size, desired = 5, 10
    else:
        min_size, desired = 2, 5
    
    asg.update_auto_scaling_group(
        AutoScalingGroupName='api-servers',
        MinSize=min_size,
        DesiredCapacity=desired
    )
```

### EBS Volume Optimization

```bash
# Find unattached volumes
aws ec2 describe-volumes \
  --filters Name=status,Values=available \
  --query 'Volumes[*].[VolumeId,Size,VolumeType,CreateTime]' \
  --output table

# Create snapshot and delete volume
aws ec2 create-snapshot --volume-id vol-1234567890abcdef0
aws ec2 delete-volume --volume-id vol-1234567890abcdef0

# Convert gp2 to gp3 (cheaper and faster)
aws ec2 modify-volume \
  --volume-id vol-1234567890abcdef0 \
  --volume-type gp3
```

## Database Cost Optimization

### RDS Reserved Instances

Calculate savings:

```python
import boto3

rds = boto3.client('rds')

# Get DB instance details
response = rds.describe_db_instances(
    DBInstanceIdentifier='production-postgres'
)

instance_class = response['DBInstances'][0]['DBInstanceClass']
engine = response['DBInstances'][0]['Engine']

# Check reserved instance pricing
# For a db.r5.2xlarge in us-east-1:
# On-Demand: $1.088/hour = $798/month
# 1-Year Reserved: $0.544/hour = $399/month (50% savings)
# 3-Year Reserved: $0.327/hour = $240/month (70% savings)
```

## Network Cost Optimization

### Use VPC Endpoints

Avoid NAT Gateway costs:

```terraform
# S3 VPC Endpoint
resource "aws_vpc_endpoint" "s3" {
  vpc_id       = aws_vpc.main.id
  service_name = "com.amazonaws.us-east-1.s3"
  
  route_table_ids = [
    aws_route_table.private.id
  ]

# DynamoDB VPC Endpoint

  vpc_id       = aws_vpc.main.id
  service_name = "com.amazonaws.us-east-1.dynamodb"

    aws_route_table.private.id
  ]
}
```
